# 产品页截图清单

Marketplace 的 Media 区是用户看到的第一屏，比文字描述更决定装不装。

## 硬性合规要求

| 要求 | 说明 |
|:--|:--|
| 尺寸 | **最小 1200×760**；几张之间**宽高比要一致**（别混 16:10 和 4:3） |
| 主题 | **不能用 IDE 默认主题**（Marketplace 明确不建议）。先换一个非默认主题再截 |
| 内容 | 只放插件相关界面；**不要**出现桌面背景、浏览器窗口、聊天头像等个人信息 |
| 清晰度 | 文字要能在缩略图里辨认 —— 所以要截**窗口区域**，不要截整屏 |

## 建议的 4 张（按重要性排序）

### 1. 弹窗本体 —— 核心入口

**截什么**：`Worktree Sync — 继承设置与会话` 弹窗完整可见。

**构图要点**：
- 来源选中主仓库那一项（下拉里能看到 `[主仓库]` 与堆值）
- 四个同步项都勾上：IDEA 构建设置 / Maven 设置 / Claude 项目配置 / Claude 会话记录
- 会话时间范围显示「最近 7 天」
- **务必让底部的「当前项目编译堆」提示行可见** —— 这一行最能体现「继承」的价值

**为什么是这张**：一眼看懂「一次选择」这个卖点。

---

### 2. 同步结果通知 —— 证明它真做了事

**截什么**：右上角的通知气泡，展开状态。

**构图要点**：让这几行都进画面
- 首行计数：`已应用 N 项 · 跳过 N 项`
- `✓ 编译进程堆 700M → 2048M（已即时生效）`
- `✓ Maven 设置 N 项（…）`
- `✓ Claude 会话 N 个（最近 7 天）`

**为什么是这张**：具体数字是可信度的来源，比任何形容词都强。

---

### 3. 同步后的 Settings 对照 —— 证明走的是官方 API

**截什么**：二者择一（若两张都截，建议合并成一张左右分屏）

- `Settings → Build, Execution, Deployment → Compiler` → `Shared build process heap size` 已是 2048（不再是 700）
- 或 `Settings → Build, Execution, Deployment → Build Tools → Maven` → `Maven home path` / `User settings file` / `Local repository` 三项都已按来源填好

**为什么是这张**：这是「不是改文件、是走 API、所以不会被内存旧值覆盖」的证据。

---

### 4. Agent 会话恢复 —— 第二组价值

**截什么**：终端里 `claude --resume` 的会话列表，或 Claude Code 的会话选择界面，显示在**新 worktree 路径**下能看到历史会话。

**为什么是这张**：把「换 worktree 就丢上下文」这个痛点直观地变成「已经解决」。

---

### 可选第 5 张：手动入口

`Tools → Sync Worktree Settings...` 菜单项被展开的状态，说明非 worktree 项目也有手动入口。

---

## ⚠️ 截图前先处理一个隐私问题

第 3 张（Maven Settings）如果直接截真实项目，会把私有环境细节一起露出去：

- 你的 `settings.xml` 路径
- 你的本地仓库目录
- 公司内网仓库域名（如果配了私有 Nexus）

**三种处理方式，挑一个**：

| 做法 | 优点 | 代价 |
|:--|:--|:--|
| **建一个 demo 项目截图**（推荐）：临时建个普通 Maven 项目 + 一个 worktree，路径用 `~/.m2` 这种通用值 | 完全无泄露，截图更通用（别人看到通用路径也更容易代入） | 多花 5 分钟 |
| 截图后打码/涂掉域名那一段 | 快 | 打码痕迹显得不专业 |
| 直接暴露 | 零成本 | 私有仓库域名与路径公开可见 |

**我建议第一种**。第 1、2、4 张同理：**弹窗截图里的项目路径**最好也是 demo 项目，别出现真实仓库名与分支名。

---

## 截完发我，我做什么

1. 统一裁剪/缩放到 1200×760（或按你选定的统一比例）
2. 逐张过合规：尺寸、宽高比、是否含默认主题/桌面背景/个人信息
3. 检查文字在缩略图尺寸下是否仍可辨认
4. 给出上传顺序建议（第 1 张是封面，决定点击率）

工具：任意截图工具截**窗口区域**即可（比整屏截图更适合产品页）。
